意
义	项目背景与痛点分析：
随着移动互联网的深度普及和用户生成内容（UGC）模式的蓬勃发展，内容社交平台已成为信息传播与社群互动的主流载体。然而，主流通用平台（如小红书、微博）在满足广泛用户需求的同时，难以有效覆盖具有高度场景化、地域化和强关系链特征的校园这一细分市场。
当前校园信息生态存在以下几个亟待解决的显著痛点：
1. 信息精准度与效率低下
海量泛娱乐化内容稀释了与学生学习、生活紧密相关的实用信息。学生难以在这些平台高效获取所需的精准信息，例如课程资料共享、社团招新通知，或本地化的校园活动。
2. 信任与传播闭环的缺失
校园内部信息的传播缺乏权威背书，官方通知与非官方信息混杂，导致信任度不足。此外，从信息发布到学生参与反馈的整个链路往往是断裂的，难以形成有效的互动闭环。
3. 垂直互动场景的空白
学生间基于共同兴趣（如考研、竞赛）或具体需求（如二手交易、求助问答）的深度互动成本高昂，主流平台缺乏针对性的垂直互动场景来促进高效、纯粹的社群交流。
平台定位与项目意义：
本项目旨在研发一款面向校园的垂直型智能社交平台——“校园蓝珊笔记”。
1. 实践与应用价值
“校园蓝珊笔记”将精准切入校园这一特定场景，通过构建严格的认证体系、精细的标签系统与定制化的推荐算法，致力于解决校园信息传播的精准性、信任度和互动效率问题。它将为师生提供一个高效、纯净、专属的校园信息交流社区，具有直接的应用推广价值。
2. 理论研究价值
本项目将协同过滤等推荐算法应用于垂直社交领域，并专注于小规模、高同质性的用户群体。这将为探索如何在特定社群生态中实现精准推荐的模型优化路径提供一次有价值的实证研究机会。
3. 技术学习与综合实践
“校园蓝珊笔记”是一个涵盖 Spring Boot 后端开发、Vue.js 前端技术、MySQL 数据库设计、Redis 缓存机制以及轻量级人工智能技术的全栈式综合实践项目，是技术能力的全面检验与提升。

	国内市场与学术现状：
国内校园社交与信息服务平台经历了从早期的 BBS、校园官网向移动化工具型 App（如“超级课程表”）的演变。但这些工具社交属性薄弱，未能形成有效的 UGC 生态。近年来，协同办公平台（企业微信、飞书）虽进入校园，其强管理属性却与学生的自发社交需求存在隔阂。主流社交平台通过“校园频道”渗透，但其底层算法难以实现校园场景下的深度垂直化运营。
学术研究方面，对校园社交平台的研究多集中于理论分析，而将先进的推荐算法与具体的校园业务场景（如活动报名、二手交易）深度融合的实证研究相对较少，存在明显的市场与学术空白。
国外市场与技术发展：
国外校园社交网络曾起源于 Facebook 的早期模式，但很快转向开放平台。目前，欧美高校主要采用以 Blackboard、Canvas 为代表的学习管理系统（LMS），其核心是内容分发与管理，社交功能并非重心。同时，Discord、Slack 等通用社群工具广泛应用于大学社团，但它们缺乏针对校园信息的结构化呈现与智能推荐能力。
技术研究层面，个性化推荐系统已是人工智能领域的热点，协同过滤、基于内容的推荐以及混合推荐模型技术已相当成熟。然而，将这些技术应用于解决特定文化背景下的校园信息孤岛和精准互动问题，仍是具有探索空间的创新方向。
综上，现有解决方案或在“社交”上失之宽泛，或在“校园”上功能单一。“校园蓝珊笔记”旨在借鉴国内外成熟技术，聚焦中国高校特有场景，构建一个集信息发布、社交互动、智能推荐于一体的垂直平台，以填补现有研究与市场实践的空白。



主
要
研
究
内
容	本研究将围绕“校园蓝珊笔记”平台的完整实现展开，核心内容分为四大板块：
1. 业务模型与系统架构设计
研究并设计一套适用于学生个体与校园组织的双角色业务模型。
构建完整的认证体系（如学号验证、组织官方认证）和内容分类体系（笔记、通知、二手、问答等）。
设计高内聚、低耦合、可扩展的系统技术架构，重点在于实现前后端分离的 RESTful API 设计。
2. 基于协同过滤的个性化内容推荐算法
这是本研究的核心内容。我们将重点研究并实现一种轻量级且高效的混合推荐算法：
基于用户的协同过滤（User-CF）： 通过分析用户的标签和行为数据（点赞、评论等）计算用户相似度，为目标用户推荐与其相似用户感兴趣的内容。
混合策略应用： 将 User-CF 与基于内容（标签）的推荐相结合，以有效缓解新用户的“冷启动”问题，并提升推荐结果的多样性。
评估与优化： 在模拟数据集或初期用户数据上，采用准确率、召回率等指标评估算法效果，并针对校园场景用户关系密集的特点进行深度优化。
3. 平台核心功能模块的工程实现
运用 Java、Spring Boot、Vue.js 等技术栈，完成平台各核心功能模块的开发与集成，包括用户管理、内容发布与浏览、社交互动、管理员后台以及推荐算法的无缝嵌入。
4. 轻量级 AI 辅助功能的集成与应用
为提高平台易用性和规范性，集成开源 AI 工具，实现两项关键辅助功能：
智能文案辅助： 利用大语言模型（LLM），为用户提供标题建议、文案润色等辅助生成功能。
违规内容过滤： 利用 LLM 对用户发布的文本内容进行初步的负面、违规信息识别与过滤。



拟采用
的研究

（方法、

证等）	研究方法：
文献研究法：系统梳理推荐算法、社交平台架构、UGC系统设计等方面的学术文献与最佳实践。
原型法：采用迭代开发模式，先实现核心功能MVP（最小可行产品），再逐步增加增强功能，便于快速验证和调整需求。
实证研究法：通过系统测试、用户访谈等方式，收集平台使用数据与反馈，对推荐算法效果和系统实用性进行评估。
技术路线：
前端：采用Vue.js框架配合Element UI组件库进行Web端开发，保证界面美观与交互流畅。
后端：使用Spring Boot框架快速构建RESTful API，整合MyBatis-Plus进行数据持久化操作。
数据层：MySQL作为主数据库，负责存储结构化数据。Redis作为缓存数据库，用于存储用户会话、热门内容列表和临时推荐结果，提升系统响应速度。
推荐算法：使用Java或Python（作为单独服务）实现协同过滤算法，通过分析MySQL中的用户行为数据，计算推荐结果并存入Redis供后端接口调用。
AI辅助：集成开源NLP模型，实现文案辅助和内容过滤功能。
可行性论证：
技术可行性：所选技术栈（Spring Boot, Vue.js, MySQL等）极为成熟稳定，社区资源丰富，学习成本可控。协同过滤等推荐算法有大量成功案例和开源库支持，实现路径清晰。
经济可行性：项目开发主要依赖开源软件与免费API，硬件需求为个人电脑及可能用到的学生优惠云服务器，成本极低。
操作可行性：项目功能设计聚焦校园真实需求，界面计划采用简约设计，用户学习成本低。开发计划时间分配合理，任务分解细致，能够在预定周期内完成。

论文（设计）选题目的、工作任务：
选题目的：
本课题旨在设计并实现一个面向高校的垂直型智能社交平台——“校园蓝珊笔记”，以解决当前校园场景下信息传播精准度不足、信任闭环缺失及垂直互动场景匮乏的核心痛点。具体目标如下：
构建一个双角色驱动的校园垂直社交业务模型与可扩展系统架构，研究并设计一套涵盖学生个体与校园组织的用户认证、内容分类与社交互动机制。设计并实现一种适用于校园垂直场景的轻量级个性化内容推荐算法，以协同过滤算法为核心，研究其在小规模、高同质性用户群体中的应用与优化策略。开发一个集信息发布、社交互动与智能服务于一体的一站式平台，完成平台核心功能模块的工程实现与集成，为师生提供一个纯净、高效、专属的校园信息交流与关系构建社区。探索轻量级AI技术在垂直社交平台中的增强应用路径，通过集成开源NLP模型，实现智能文案辅助与违规内容过滤两项辅助功能，以提升平台易用性与内容规范性。
工作任务：
校园垂直社交平台的业务模型与系统架构设计，深入分析校园场景需求，完成包含用户体系、内容体系、互动机制在内的详细业务模型设计。个性化内容推荐算法的研究、实现与优化：本研究的技术核心任务。重点研究基于用户的协同过滤算法在校园场景下的适用性，并设计混合推荐策略。平台核心功能模块的开发与集成，依据系统设计，运用Spring Boot、Vue.js等技术栈进行全栈开发。具体包括用户管理、内容发布与浏览、点赞评论关注等社交互动、活动报名、管理员后台等功能模块的编码实现，并将各模块集成为一个可稳定运行、可演示的完整Web应用系统。轻量级AI辅助功能的集成与应用：构建独立的Python微服务，实现智能文案辅助生成与违规文本内容过滤功能。通过API接口与主平台对接，完成两项AI功能的前端界面展示与后端逻辑集成。系统测试、评估与文档撰写，对完整平台进行全面的功能测试、性能测试及用户体验测试，修复缺陷并优化系统。基于测试结果与模拟运行数据，对推荐算法效果及系统整体实用性进行评估。最后，系统化地整理开发过程、技术实现与研究成果，撰写毕业论文。

一、研究背景
随着移动互联网从“泛娱乐化”向“场景化”深度演进，用户生成内容（UGC）已成为高校信息传播的核心载体。赵宇翔等（2012）通过“Who-What-Why-How”四维模型解构了UGC的本质，指出用户动因涵盖了兴趣乐趣与自我效能等多重因素[1]，这为理解校园个体的创作行为提供了理论支撑。然而，现有的通用平台（如微博、小红书）由于缺乏地域垂直性和校园身份认证，导致学生在获取课程资料、社团通知、二手交易等实用信息时，面临严重的“信息过载”与“信任缺失”痛点。在国内宏观政策方面，教育信息化2.0行动计划强调构建数字校园生态体系，而高效的校园信息流动是实现该目标的关键。在实际运行中，主流平台算法往往向流量倾斜，忽视了校园小规模、高同质性群体的精准需求。基于此，本研究旨在通过开发“校园蓝珊笔记”平台，利用 Spring Boot 架构结合改进的协同过滤算法，构建一个集信息发布、智能推荐与 AI 治理于一体的垂直社交空间，为校园精准社交与信息高效传播提供技术方案。
二、研究现状
（1）概括
国内外关于社交平台与推荐系统的研究已历经数十年发展。国外研究起步较早，从 Facebook 的校园实名社交模式演进到如今 Canvas 等学习管理系统与 Discord 等即时通讯工具的结合；国内则经历了从 BBS 到工具型 App 的转变如张振球（2019）实现了基于 Spring Boot 的校园文章发布系统，体现了内容发布与管理的技术基础[2]；张豪等（2023）通过 B/S 架构设计了集成爬虫功能的校园论坛，提升了信息的聚合能力[3]；钟育伙（2024）则进一步探索了基于 Spring Boot+Vue 的校园活动管理，实现了垂直场景下的全生命周期管理[4]。这些成果证明了技术栈的成熟，研究手段已从早期的基于规则的检索，发展为如今以机器学习和深度学习为核心的智能推荐系统。目前，研究结论普遍认为，提升垂直社区活力的关键在于“架构的稳定性”与“推荐的精准度”。
（2）分析
在系统架构层面，吕宇琛（2018）《Spring Boot框架在web应用开发中的探讨》中指出：Spring Boot 凭借“约定优于配置”和“开箱即用”的核心策略，能显著减少 XML 繁琐配置，提高 Web 应用的开发敏捷性[5]。此观点的提出，为本项目构建前后端分离的 RESTful 架构提供了工程化支撑，但该研究主要聚焦于通用 Web 开发，未深入探讨在高并发社交场景下的性能优化。
在推荐算法演进方面，《Neurocomputing》（2025）发表的综述《A collaborative filtering recommender systems: Survey》全面梳理了协同过滤（CF）从传统内存型向深度学习（如 AutoEncoder, GNN）演进的路线[6]。该文指出，深度学习虽能处理复杂特征，但计算成本高；而混合推荐策略是解决数据稀疏与冷启动的最佳实践。这启发了本项目在校园小样本环境下应采用轻量级混合策略，而非盲目追求重型模型。
在算法优化实证方面，鲁为（2007）在《协作过滤算法及其在个性化推荐系统中的应用》中通过实验证实：使用奇异值分解（SVD）对评分矩阵降维，并采用 Pearson 相关系数代替余弦相似度计算邻居，能显著降低平均绝对误差（MAE）[7]。该研究为本项目解决校园新用户“冷启动”问题提供了数学依据，但由于年代较早，未能涵盖生成式 AI 在内容治理中的协同作用。
（3）整合回顾
基于以上研究，现阶段校园社交平台仍存在以下不足：一是现有架构多偏向管理属性，缺乏对 UGC 内容生态的灵活支撑；二是推荐算法在校园小规模群体中容易陷入局部最优，且对非结构化数据的处理能力不足。
改进方向应聚焦于：一是为校园信息流找到一个恰当的、富有生命力的内容载体。本项目认为图文笔记可以作为校园垂直社交的核心载体与基础单元。二是将传统的 User-CF 算法与 LLM（大语言模型）结合，通过 AI 辅助文案生成与违规过滤，增强社区内容的纯净度与互动深度。
三、结论
通过对既有研究的梳理与评述，本综述得出以下核心结论，它们直接定义了“校园蓝珊笔记”项目的设计根本：
（1）校园垂直平台的突围，关键在于构建 “身份×场景”的闭环生态。必须融合实名认证的信任基础与具体校园场景的精准需求，打造一个深度嵌入真实校园网络的高效信息中枢。
（2）确立 “图文笔记”为统一内容载体，是激活UGC生态的关键。其半结构化的特性，能自然承载全场景信息，支撑构建一个可生长、可演化的内容网络，而非静态的管理系统。
（3）校园推荐需从“追求绝对精度”转向 “平衡精度与场景”。应采用轻量级、基于场景的混合推荐策略，深度融合身份属性与实时行为，以破解小样本下的冷启动与信息茧房问题。
（4）LLM（大语言模型）的价值应从“后端治理”前置为“全程赋能”。通过辅助创作与智能治理，AI将成为提升社区内容质量与互动效率的核心引擎，实现生态的质量自增强。
