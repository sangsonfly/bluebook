# 图片资源说明

## 📁 文件夹用途
这个文件夹用于存放笔记平台的图片资源，包括：
- 笔记封面图片
- 用户头像
- 其他媒体资源

## ➕ 如何添加新图片

### 方法1：直接添加图片文件
1. 将图片文件（jpg, png, gif, webp等格式）复制到此文件夹
2. 在 `js/main.js` 中的 `notesData` 数组中添加新的笔记数据
3. 使用相对路径引用图片：`files/你的图片文件名.jpg`

### 方法2：修改现有笔记数据
打开 `js/main.js` 文件，找到 `notesData` 数组，修改对应的 `image` 或 `avatar` 字段：

```javascript
{
    id: 1,
    title: '你的笔记标题',
    image: 'files/你的图片.jpg',  // 笔记封面图
    author: '作者名',
    avatar: 'files/头像.jpg',      // 作者头像
    likes: 1234,
    tags: ['标签1', '标签2']
}
```

## 🎨 推荐图片规格
- **笔记封面图**：宽度 300-800px，高度 350-500px
- **用户头像**：正方形，推荐 80x80px 或更高
- **文件格式**：JPG, PNG, SVG, WebP
- **文件大小**：建议单张图片不超过 2MB，以确保加载速度

## 🔧 图片加载失败？
如果图片无法显示，请检查：
1. ✅ 图片文件是否存在于 `files/` 文件夹中
2. ✅ 文件路径是否正确（区分大小写）
3. ✅ 图片文件是否损坏
4. ✅ 浏览器控制台是否有错误信息

系统已配置了图片加载失败的自动处理机制，会显示美观的占位符。

## 💡 提示
- 为了更好的性能，建议使用压缩后的图片
- 可以使用在线工具如 TinyPNG 来压缩图片
- SVG 格式适合图标和简单图形，文件小且不失真
